# 🧪 EXPERIMENTS with GitHub Copilot in `hello` Repository

Цей файл допоможе протестувати основні можливості GitHub Copilot у VS Code та GitHub Copilot Chat.

---

## 1. Автогенерація коду
- [ ] Створити новий файл `app.js` або `main.py`.
- [ ] Написати коментар:  
  ```js
  // Функція для перекладу слова з англійської на українську
[ ] Перевірити, як Copilot пропонує готову функцію.
2. Пояснення існуючого коду
[ ] Відкрити файл docs/index.html.

[ ] Запитати у Copilot Chat: “Поясни, що робить цей файл і навіщо він потрібен у репозиторії?”
3. Генерація тестів
[ ] Додати просту функцію, наприклад:

js
function sum(a, b) {
  return a + b;
}
[ ] Запитати у Copilot Chat: “Згенеруй юніт‑тести для цієї функції з використанням Jest.”
4. Рефакторинг
[ ] Написати довгу або неефективну функцію.

[ ] Запитати у Copilot Chat: “Оптимізуй цей код для кращої продуктивності та читабельності.”
5. Документація
[ ] Попросити Copilot додати JSDoc/Docstring до функції.

[ ] Створити Pull Request на GitHub.

[ ] Запитати Copilot Chat: “Згенеруй опис змін для цього PR.”
6. Інтеграція з GitHub Copilot Chat
[ ] Відкрити репозиторій hello на GitHub.

[ ] У Copilot Chat запитати: “Поясни останній коміт у цьому репозиторії.”
7. Експеримент з GitHub Pages
[ ] Запитати Copilot Chat: “Як налаштувати GitHub Pages для цього репозиторію?”

[ ] Перевірити, чи відображається сторінка з docs/index.html.
